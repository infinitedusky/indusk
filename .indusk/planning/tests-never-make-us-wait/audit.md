## Which rejected ADR alternative does the code quietly take?
- `apps/indusk-mcp/src/lib/plans/test-set-run.ts:23` — Observed in Vitest 4.1.11's source: a related run whose input matches the default rerun triggers (`**/package.json/**`, `**/{vitest,vite}.config.*/**`) returns every test. The ADR rejected "Run the whole suite at landing, only faster", and this reaches the same result, at every phase, by another path.
