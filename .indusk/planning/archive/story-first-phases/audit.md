# Audit — story-first-phases

## Does each row prove its promise's sentence, or something narrower?
- `apps/indusk-mcp/hooks/validate-impl-structure.js:224` — `an-impl-phase-explains-itself` (the promise that an opted-in impl missing a phase paragraph, or with code or a row label on a task line or a row label in the paragraph, is refused). The save check returns early when the incoming text has no phase heading, no `- [ ]` and no `**Tier**:` line, and it does this before the new rule runs. I ran the hook on an opted-in fixture. An Edit that turns the paragraph into "This phase makes A4 pass." exits 0. So does an Edit that deletes the paragraph, and so does an Edit that rewrites a ticked task as ``- [x] The thing in `foo.ts` is done``.
