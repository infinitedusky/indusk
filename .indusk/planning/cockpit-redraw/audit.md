# Audit — cockpit-redraw

## Does each row prove its promise's sentence, or something narrower?
- `apps/indusk-mcp/hooks/looks-approval-guard.js:62` — `only-a-person-reapproves` says `indusk plans reapprove` run from an agent's tool call is refused. Rows A5, A6, A13 and A14 (trajectory rows: the CLI refused, the route refused, a substitution under a reader refused, an interpreter naming `reapprovePlan` refused) cover the spellings they list and nothing else. Two other ordinary spellings get through, and I checked both by piping a Bash event into the hook (the hook only; the commands themselves were never run). `indusk plans "reapprove" x` exits 0, because `REAPPROVE_COMMAND` needs whitespace right before `reapprove`, so a quote there stops the match. `indusk plans \⏎ reapprove x`, a backslash line continuation, also exits 0: `segments()` at :92 splits on newlines, so neither half matches. A one-character change to the command gets past what the rows prove.
- `apps/indusk-mcp/src/__tests__/looks-approval-guard.test.ts:179` — A5 asserts "…and the plan's approval is unchanged". The test checks only the exit code and stderr. Nothing in it reads `approved_brief` before and after.

"Each updated as it writes" is backed only by A11, a manual live check, while the trajectory says the promise "is proven by A8, A9 and A10". None of those three tests anything updating as the agent writes.
- `apps/indusk-admin/src/components/cockpit/CockpitFrame.test.tsx:106` — A1 (a trajectory row: dragging past the widest or narrowest width stops there) proves that the drag stops at some bound below 1280 px, and that the narrowest is ≤ the opening width.
