# A root CLAUDE.md Key Decisions line pointing at a raw adr.md (not /decisions/*) must wait until the plan archives — not be added at ADR acceptance

Twice in the same session (planner-promises, commit 8cdf0186; admin-plan-authoring, commit 4a311331), a Key Decisions entry was added to the root CLAUDE.md immediately on ADR acceptance, pointing directly at `.indusk/planning/<plan>/adr.md` — the plan's live, in-progress path. Every other Key Decisions line in CLAUDE.md that points at a raw `adr.md` file (as opposed to a published `/decisions/<slug>` page) points at an *already-archived* plan, i.e. `.indusk/planning/archive/<plan>/adr.md`. A plan's retrospective moves its directory from `.indusk/planning/<plan>/` to `.indusk/planning/archive/<plan>/` when it closes — so a pointer added at ADR-acceptance time (well before the retrospective) is written against a path the plan is guaranteed to vacate later.

Why it matters: `indusk context check-pointers` validates that every pointer in every context file resolves to a real path *right now*. It cannot detect a pointer that is correct today but scheduled to break on a future, already-planned move (archival) — so the check passes at the moment the line is added and silently starts failing only once the retrospective runs, unless whoever writes the retrospective happens to remember this one CLAUDE.md line needs its path updated to `archive/`. Nothing currently tracks that obligation.

What to do: when adding a Key Decisions line that cites a specific `adr.md` (not a `/decisions/*` docs-site page), either (a) wait until the plan's retrospective has archived it, and write the line with the `archive/` path from the start, or (b) if the line must be added at acceptance time for immediate usefulness, add a note or TODO that the retrospective step must update this specific CLAUDE.md line's path when it archives the plan. Prefer (a) — every other precedent in this file already follows it. See `.indusk/planning/archive/planner-promises/adr.md` and `.indusk/planning/admin-plan-authoring/adr.md` for the two instances; `apps/indusk-mcp/skills/claude-md.md` is the skill that should eventually encode this rule.
