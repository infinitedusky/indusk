# A look/page check that 404s against a real project isn't the run failing — it's telling you the project doesn't have that page; design the check to report it as unchecked, not crash the whole run

A check that walks a fixed list of pages/screens (`screens.json`, a sitemap, a route table) and opens each one will hit a 404 whenever the list names a page a given project doesn't actually have — a fixture-only route, a feature not enabled there, a page that was renamed. Treating that 404 as a run failure (throwing, aborting the whole check) conflates "the check's tooling is broken" with "this is simply a fact about this project's shape." The check should keep going and report that one page as unchecked-with-reason, not end the run for every other page too.

**Why:** cockpit-redraw (dusk, 2026-10-14, archived at `.indusk/planning/archive/cockpit-redraw/`). `screens.json` pointed at fixture-only paths, so `indusk looks check admin` 404'd and ended the entire run against a person's own real project — unusable, and nothing in the plan's own trajectory ever ran the check against a real project to notice. The cold audit caught it (not the builder's own falsification). The fix (Build Phase 6) made a 404 report as an unchecked look, named, with the run continuing: against the real project, 550 held, 0 broken, 182 unchecked. The retrospective's own words: "A look check opens pages; a page the project does not have is a fact about the project, not a failure of the run."

**How to apply:** when building any check that iterates a fixed list of targets (pages, screens, endpoints) and opens/queries each independently, make one target's absence (404, not-found, feature-disabled) degrade to "unchecked, named, reason given" rather than aborting the whole run — the same resilience pattern as a timeout (see the related storybook-components finding on timeouts never ending a run). And run the check against a real target at least once during the build, not only against the plan's own fixtures, or this exact gap is invisible until a cold audit or a person hits it.
