# A falsification test authored against the fixture that revealed the original bug inherits that fixture's coverage gap — when the fix touches a conditional, author a fixture for every branch, not just the one already in hand

worktree-config-schema-pointer's Phase 2 falsification wrote A6 to prove a package-owned file (`config.schema.json`) never leaks into a shared workbench repo. A6's fixture declared `repos: [{ name: "alpha" }]` — no `worktrees` field — because that was the fixture shape already in scope from earlier phases. The fix it verified (`topUpManagedIgnore`) sits behind `refuseIfIgnoreCannotHold`, which has exactly two branches: `allLocationsDeclared(repos)` true (declared layout, early return) or false (flat layout, the branch A6's fixture exercises). A6 passed convincingly and Phase 2 closed the plan. The declared-layout branch — the one A6's fixture structurally could not reach — silently kept the original bug: a declared workbench's ignore file never got the top-up at all. It was found four days later during a retrospective docs audit, not by the falsification ritual whose stated goal was exactly this class of failure.

This is a different gap from `lifecycle-edges-in-original-trajectory` (which is about long-lived entities transitioning over time). This is about a **conditional with N branches** where the fixture on hand only ever drives one of them, and nothing in the falsification process prompted checking the others.

**How to apply:** when a falsification hypothesis targets a function with a conditional (an `if`/branch on some property of the input), enumerate every branch explicitly and confirm a fixture exists that drives each one — do not accept "the fixture I already have covers this" as sufficient. If the fix under test reads a flag like `allLocationsDeclared`, `isWorkbench`, `layoutDeclared`, write down both `true` and `false` cases before writing the assertion, even if only one seems relevant to the immediate bug. See `.indusk/planning/worktree-config-schema-pointer/impl.md` Phase 4 and `apps/indusk-mcp/src/__tests__/worktree-config-schema-versioned.test.ts` (A6 vs A8).
