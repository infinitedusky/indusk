# Widen a static guard to every case of the class (all globbed files, all specifier forms) before trusting it; have a cold reader try to defeat it

In template-reload-on-cold-cache the pre-bundle guard first checked only named @opentelemetry imports in two hard-coded files. Falsification widened it to every bare specifier in every globbed file; the cold audit still found subpath imports collapsed to their package. Three readers were needed to get one static check right. A guard written beside its fix encodes the author's imagination. Enumerate the class (glob the files, parse every specifier form including subpaths) and run the guard against a deliberately reworded violation.
