# An ADR that decides "delete this test file, keep that one" from a list of file names, before anyone has read every assertion inside each file, will get the fate wrong for any file that asserts more than its name suggests

In test-kinds (`.indusk/planning/archive/test-kinds/`), the accepted ADR said "delete the eight admin HTTP promise-test files, keep one trimmed as a contract test" — a decision made by looking at the eight file names and reasoning about what kind of test each file plausibly was (a slow, server-booting integration test duplicating what new unit tests would cover). When Build Phase 2 actually read every assertion inside each of the eight files, six of them turned out to also assert page-level rendering behavior (incident bands, the source-switch control, the sidebar's red indicator, the watcher-blind banner, live refresh) that no unit test reached — only the HTTP test exercised the full page. The ADR's "delete eight, keep one" became "delete two, move six to the system tier" once the actual assertions were read.

This was caught, not missed, because the impl's own stated rule ("delete only when every assertion is covered") forced someone to actually check coverage before deleting — if that rule hadn't existed, six files' worth of real page-level test coverage would have been silently deleted on the strength of an ADR sentence written from file names, not file contents.

**How to apply:** when an ADR or any planning document decides a test file's fate (delete it, keep it, convert it, merge it) based on the file's name, its apparent purpose, or a general sense of what kind of test it is, that decision is provisional until every assertion inside the file has actually been read and accounted for in the replacement. Write the rule explicitly into the impl ("delete/convert only once every assertion is covered by something else") rather than trusting the ADR's upfront classification — a file can assert more than its name or its dominant pattern suggests, and the only way to know is to read it.

See `.indusk/planning/archive/test-kinds/retrospective.md` ("Diverged from the plan", "What We'd Do Differently": "Read every assertion of a file before the ADR decides its fate").
