# A clause's signal must read a source independent of the code it judges and be able to report broken — never a display compared with its own producer, a hook reporting its own decisions, or an event that may never occur

The a-run-can-be-trusted plan review found signals planned that could never go red: the page compared against the function that produced the page, a hook reporting about its own verdicts, and one relying on an event that may never happen. A signal like that reads upheld whatever the truth is, so `clauses: required` closes on nothing.

Rule: when writing a signal task, name (1) the independent source it reads (the record on disk, git, the files, a live process) and (2) the observation that would make it report broken. If the source is the judged code's own output, or no real run can trigger the broken case, the signal is rewritten or the clause is proved by tests alone and says so.
