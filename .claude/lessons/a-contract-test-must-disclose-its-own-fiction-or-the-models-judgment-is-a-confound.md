# A contract test driving a model through a fictional scenario must disclose the fiction, or the model's own judgment becomes a confound indistinguishable from the hook under test

publish-hygiene's A24 (build-session-gates.test.ts) drove a real `claude` session against a fixture plan with an unbuilt checklist item, asking it to check the item off, to test whether InDusk's gate hooks would allow or refuse the edit. After an earlier fix made the prompt read the file first (so an unread Edit wouldn't fail for an unrelated reason), a new failure appeared: the model read the fixture plan, recognized that checking off unbuilt work would misrepresent reality, and refused on its own ethical judgment — before any hook ran. The test then measured whether the model's conscience objected, not whether the gate hook did; a refusal from either path looks identical in the test's events.

This is a different failure mode from the already-recorded `a-test-that-offers-the-model-a-way-out-tests-the-models-choice-not-the-contract` lesson (which is about an explicit escape hatch in the prompt, e.g. "if you can't, say DENIED"). Here there was no escape hatch — the model took the only action offered (the edit) and then independently refused based on context the prompt never gave it. The fix was to make both contract prompts (A24's and A1's, `session-protocol-contract.test.ts`) state plainly that the project is a test fixture and what is being tested, so the model's own judgment is not a variable the test has to control for.

How to apply: when a contract test drives a real model through a scenario designed to probe infrastructure (a hook, a gate, a permission system) rather than the model's judgment, state the fictional/test nature of the scenario explicitly in the prompt. Otherwise the model's independent reasoning about the scenario's legitimacy is a second, uncontrolled decision point sitting in front of the one actually under test, and a refusal can come from either — indistinguishable in the test's output, and liable to flip between model versions. See `.indusk/planning/archive/publish-hygiene/retrospective.md` and commit 9935ae32.
