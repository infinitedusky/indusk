# A live check on a framework's default shape proves only that shape — falsification lists the non-default layouts the framework's own generator offers (src-dir, strict package resolution, bundled wrappers)

T11, the live check of a-new-project-starts-instrumented, passed on a root-layout Next.js app. The falsification then found three ways a real app reported nothing: `create-next-app --src-dir` puts app/ under src/ so a root instrumentation.ts is never loaded; pnpm's strict layout does not resolve @opentelemetry/api as a peer so the helper's import fails; and `opentelemetry-instrument` builds its own provider before the scaffold loads. Rule: after a live check passes, the falsification phase enumerates the options the framework's generator itself offers (source folder, package manager strictness, language wrappers and launchers) and tests each as a hypothesis; one live check is a rehearsal of one shape.
