# A falsification/hypothesis test that passes on day one is not automatically a real falsification test — ask why it's green before marking the row written

writing-skill's falsification phase authored A25 ("the destination index reorders correctly on a hotfix publish") and it passed immediately. The reason it passed was uninteresting: the index regenerates *before* the destination commit lands, so on the very next publish the reorder is already reflected — the test's assertion window happened to sit after the regeneration but before the boundary where the real defect (a hotfix publish landing without triggering a reorder at all) would show up. Extending the test past that boundary — checking the index state across the publish that actually exercises the timing gap, not just the one immediately after — turned it red on the real defect.

This is the falsification-ritual-specific instance of the general discipline in `verify-fault-injection-before-authoring-the-test` (verify an induction produces the failure, for the right reason, before authoring around it) and `ask-what-a-check-proves` (name the failure a check is supposed to catch, then ask whether green actually rules it out). The falsification twist: a hypothesis test's whole point is to try to break something, so a same-day green is the *one* result that should trigger the most scrutiny, not the least — a green falsification row that nobody interrogated is indistinguishable from a row that never actually tested the hypothesis.

**How to apply:** when a falsification-phase hypothesis test is authored and passes without ever going red, before marking the row `written`, ask explicitly: what would have to be different for this to fail, and does the current test actually reach that state? If the answer is "the test's window sits before the boundary where the real risk lives," extend the test past that boundary rather than accepting the green. This is a specific version of the falsification ritual's own goal-flip ("prove it works" → "find a failing test") applied reflexively to a row that resisted the flip.
