# Read a check's skips before naming it as a promise's measure: a check that skips the hard case reports the easy one as proof

The composition check (A30) ran at one width and skipped every box holding a mockup's own words, yet the brief named it as the measure of "drawn at each reference device". Only the cold audit saw the gap; when the check was widened (T7, every device, the mockup's words given to the story), it went red 611 lines on the phone.

How to apply: before a brief or impl names a check as a promise's measure, read what the check skips and which inputs it draws at; if a skip covers the promise's hard case, widen the check or say so in the row.
