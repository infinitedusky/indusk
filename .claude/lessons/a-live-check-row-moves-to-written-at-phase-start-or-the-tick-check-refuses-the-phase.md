# A live-check row (a person's look, no test file) must move from planned to written at the start of its phase, or the tick check refuses every tick in that phase

A row with no test file stays 'planned' because nothing writes it, and the gate then refuses every checkoff in its phase. In story-first-phases A13 and A20 were moved to 'written' at phase start for this reason. When a phase holds a live-check row, flip it to written in the phase's first commit and to passing when the person has acted. The work skill should state this.
