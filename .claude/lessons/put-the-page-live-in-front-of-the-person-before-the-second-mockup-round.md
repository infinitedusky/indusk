# Before a screen's second round of mockups, put the running page in front of the person — a design approved as mockups changes the first time they use it

Mockups are approved as pictures; the structure of the work shows up when the person uses the live page.

Why: in brief-as-the-contract the plan page's mockups were approved three times, then Sandy used the admin on the last day and the real design appeared (the brief gets its own page with the agent beside its parts; the plan page opens with a description and the brief's state; status first with parts folded; documents open in place). That restructured the page after the mockups, stories and tests had been built to the earlier one (retrospective, 'What We'd Do Differently').

How to apply: after the first approved mockups of a new screen, build the thinnest working page and have the person use it before drawing the next round; record what they did and wanted in the plan, then redraw. Pairs with `a-page-draws-what-its-approved-mockup-draws-and-nothing-else`: the mockup is the spec, so the spec should be tested by use early.
