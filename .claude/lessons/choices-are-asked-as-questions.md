# A choice an unattended run cannot settle is asked as a question, never recorded as decided

When an unattended run (INDUSK_GATE_POLICY=auto) meets a choice the plan does not settle, ask it with the ask_decision tool: at least two options, the one you recommend and why, a cost (cheap, moderate, expensive), and what each option changes (brief, promise, look, gate). Then cite the question on the line that records the choice: "Use SQLite. Decided unattended (question: q-3)." A saved plan document that says "decided unattended" with no question reference, or one the plan's record does not hold, is refused by hooks/validate-decided-unattended.js. Why: a silent decision is one the person meets only at approval; a question is visible with its recommendation, and its cost setting decides whether the run waits.
