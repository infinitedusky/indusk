# The lessons registry accumulated 7 near-duplicate advisory lessons for one incident (evaluator git-stash in watcher-heartbeat) and the hazard still recurred — a lesson nobody enforces is not a lesson learned

Seven lessons in `.claude/lessons/` — `evaluator-never-runs-git-mutating-commands-in-graded-worktree`, `eval-agent-never-runs-mutating-git-commands-in-the-worktree-it-grades`, `an-evaluator-grading-a-branch-must-never-run-mutating-git-in-that-branchs-worktree`, `the-evaluator-and-a-persons-test-run-collide-in-one-worktree`, plus three more collision-flavored variants — all restate the same watcher-heartbeat incident (2026-10-03, `git stash` at 20:22:07, stash `8d97ef80`, same timestamp and same lost `telemetry.ts` re-export cited in every copy). All seven are `state: advisory`, `guardedBy: []` — none was ever turned into a test.

The hazard they describe recurred anyway: the `bookkeeping-lives-where-it-is-read` plan (2026-10-07) rediscovered it from scratch as trajectory row A12 ("found building this plan: the evaluator stashed, checked out and popped in a live worktree") and had to re-author the fix (`permissions.ts`, commit `254c3f46` → `9449def4`) — the exact rule seven existing advisory lessons already stated.

**Why this matters:** advisory lessons are skimmed by title at catchup, not deep-read, and skimming seven near-identical titles is not meaningfully safer than skimming one — the duplication added re-reading cost without adding coverage. The actual fix only happened when the hazard got promoted to a Test Trajectory row with a guard (`permissions.test.ts`, lesson-token-bearing), i.e. when it stopped being advisory.

**How to apply:** when writing a new lesson, grep `.claude/lessons/` for existing titles covering the same incident or rule before calling `add_lesson` — if found, either skip (duplicate) or strengthen the existing one (add detail, or better, promote it to guarded by wiring a test that names it in a failure message). Don't let an unenforced lesson's repeated restatement substitute for giving it a guard. A lesson that has recurred more than once despite an advisory entry is itself a signal: write it up for a plan to add an enforcer, not another lesson file.
