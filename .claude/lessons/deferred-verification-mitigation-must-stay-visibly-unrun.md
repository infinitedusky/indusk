# A deferred-verification row mitigated by a downstream plan is only honest while that plan's unrun state stays visible somewhere a reader will see it

When a Deferred Verification row (U1/U2-style: `reason:` / `would require:` / `mitigation:`) points at a downstream plan as its mitigation, that mitigation is only valid the moment the downstream plan's brief is accepted — and it decays back into a pass asserted without observation the moment the artifact it produced (a Docker image, a `fly.toml`, a deploy config) is described anywhere as working without having actually been run.

**Found during day-always-on's retrospective audit**: U1 and U2 (the Fly deploy smoke) were classified `downstream-plan`, no warning — correctly, because the user had accepted day-always-on-deploy's brief specifically to make that mitigation valid. The condition that kept it honest was narrower than "a plan exists": the guide had to mark the image and the fly.toml as UNRUN in a warning callout until that plan closed. Shipping the same artifacts under the word "reference" instead — dropping the UNRUN callout because the config looks plausible — would have been a pass asserted without observation, indistinguishable from a real deploy smoke to anyone reading the guide later.

**The rule:** when a deferred-verification row's mitigation is "a downstream plan will run this for real," find where that unrun artifact is described to a reader (a guide page, a README, a changelog entry) and confirm it still says UNRUN/reference/not yet executed — not just that the downstream plan exists in the planning folder. The mitigation lives in two places (the deferred-verification row and the reader-facing doc); both must agree, and the doc is the one a future session actually reads.

**How to apply:** at retrospective time, when auditing Deferred Verification rows classified `downstream-plan`, don't stop at "does the named plan exist and is it accepted" — grep the guide/doc surface the mitigation depends on for the warning callout it promised, and treat its absence as the row silently going back to unmitigated.
